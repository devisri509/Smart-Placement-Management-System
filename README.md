# Smart Internship & Placement Management System

A full-stack web application for managing student profiles, internships, job applications, and placement activities.

## Tech Stack

- **Frontend:** React
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## Project Structure

- `frontend/` – React application
- `backend/` – Spring Boot application
- `database/` – SQL scripts
